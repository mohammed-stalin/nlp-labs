## Using the notebooks

Open a lab folder and read its README for the exercises and requirements. Launch Jupyter from that folder so relative dataset paths resolve correctly. Install the dependencies required by the notebook in your Python environment.

## Repository history

The four original repositories were imported into the folders above with their full main-branch Git histories. These are ordinary folders in a single repository; cloning this repository includes all labs and datasets.

Original files, including notebook outputs, supporting documents, datasets, and any lab-specific license, are preserved as imported.
